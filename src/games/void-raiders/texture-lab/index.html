TURRET TEXTURE LAB

Wraps a texture around the procedural turret head spheres so we can iterate the look before committing.

Generate via Gemini

Run from terminal:

npm run texture -- "..." --name v1

New PNG appears in public/textures/turrets/. Click Refresh to load it.

Save for the game

Persists the currently-applied textures to localStorage. The mothership reads these on load and wraps them on every in-game turret.

Actions

Tips

Equirectangular sphere textures want a 2:1 aspect. Gemini usually returns 1:1 — that still works but the poles will pinch. Add "seamless equirectangular sphere texture, 2:1 layout, top half = top of sphere" to the prompt.
